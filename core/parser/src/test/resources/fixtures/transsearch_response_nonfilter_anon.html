styx42 : bien vu, c'est exactement ça. Il y a deux mécanismes distincts dans la vue Drapeaux.

 

[list]

  • Un throttle d'auto-refresh global, ~15 s : à l'ouverture de l'app, l'onglet visible se rafraîchit. Ensuite chaque changement d'onglet redemande bien un rafraîchissement, mais si moins de 15 s se sont écoulées depuis le dernier (sur n'importe quel onglet), le fetch réseau est sauté pour ne pas marteler HFR.
  • Un cache par onglet, TTL ~30 s : chaque type (Cyan / Lu / Favoris) garde ses données séparément. Dans la fenêtre des 15 s, le nouvel onglet affiche donc son cache ; s'il est périmé (> 30 s), un fetch part quand même en arrière-plan, sans spinner.

[/list]

 

Donc oui : un onglet consulté pour la première fois juste après le lancement (dans les 15 s) peut montrer des données un peu datées sans rafraîchissement forcé. Le hic, c'est que cette temporisation est globale alors qu'elle gagnerait à être par onglet, pour que la première ouverture de chaque onglet le rafraîchisse indépendamment. C'est noté et tracé : https://github.com/ForumHFR/redface2/issues/743

 

Merci pour le diagnostic, il était juste.
