Et voila le topic unique sur Claude!  
 
Présentation
 
Anthropic est une société américaine fondée en 2021 par Dario et Daniela Amodei, anciens d'OpenAI. Elle développe Claude avec une approche centrée sur la sûreté et l'alignement des modèles, et bénéficie d'investissements significatifs de Google et Amazon.
 
La gamme
 
- Opus : modèle haut de gamme pour les tâches complexes (raisonnement, code, rédaction longue)
- Sonnet : compromis perf/vitesse, adapté à la plupart des usages
- Haiku : modèle léger et rapide
 
Accès via claude.ai, les applications iOS / Android / desktop, l'API via la console, et Claude Code en CLI.
 
Ressources utiles
 
- Documentation officielle
- Guide de prompt engineering (balises XML, few-shot, etc.)
- Centre d'aide
- Tarifs (Free, Pro, Max, Team)
- Blog Anthropic
 
Veille
 
- X : @AnthropicAI et @claudeai
- r/ClaudeAI
 
Quelques conseils
 
- Un prompt précis (contexte, format attendu, ton) change radicalement la qualité de la réponse
- Pour les longs documents, préférer la pièce jointe au copier-coller
- Les Projets (offre Pro) permettent de conserver un contexte documentaire persistant entre conversations
- Les Artifacts facilitent l'itération sur code et documents structurés
- La recherche web est activable selon les besoins
 
Objet du topic
 
Centraliser retours d'expérience, comparaisons avec la concurrence (ChatGPT, Gemini, Mistral, DeepSeek), cas d'usage et actualités. Les questions techniques sur l'API ou les fonctionnalités sont bienvenues.
 
N'hésitez pas à partager vos impressions.

Voici ce que j'ai dû faire pour installer claude code pour l'utiliser avec Android Studio :
 - dans android studio > Paramètres > Plugins > Installer "claude Code (beta)"
 - installer Node JS pour windows : https://nodejs.org/fr/download
 - installer GIT pour windows : https://git-scm.com/install/windows
 - ouvrir un invite de commande en Admin
 - taper "npm install -g @anthropic-ai/claude-code"
 - fermer puis rouvrir le terminal
 - dans le terminal : cd c:\mon-dossier-projet\
 - taper CLAUDE et répondre à quelques questions
 - ça va demander de s'identifier (ouverture du navigateur, obetenir un code et le coller dans le terminal).
 - ça va demander si vous avez confiance dans le dossier (faire attention que c'est bien le chemin du projet et non pas c:\windows\system32 par ex)
 - lui demander de créer un CLAUDE.md

Xat, t'as des infos pour connecter adb / lui faire exploiter la VM ?


Oui. adb tu lui demandes de l'installer si tu ne l'as pas déjà. Sous windows peut être avec Winget. adb gère la connection avec un android, via USB ou TCP (wifi possible donc).
Mais déjà tu demandes à Claude en CLI de te faire une todolist et qu'il en fasse le plus possible
Mais en gros tu créé le device qu'il te demande de créer sur Android Studio / Virtual Devices Manager
Puis avec adb il trouve et se connecte tout seul à l'android émulé, puis il peut faire ce qu'il fait : installer une APK, naviguer, prendre des screenshots (et les analyser), etc.
