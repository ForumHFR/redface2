Reprise du message précédent :
Redface 2 dev 0.53.6 (app-v305) est disponible sur le dépôt F-Droid dev.

 

Correctif de la 0.53.5 sur l'onglet Super, après un audit complet du câblage entre l'écran et ses réglages :

 

- Pull-to-refresh sur Super : le corps de cet onglet n'avait tout simplement pas de détecteur de geste, d'où l'absence totale d'animation. Le rafraîchissement livré en 0.53.5 existait mais n'était jamais atteint depuis l'écran. L'onglet passe maintenant par le même corps de liste que Cyan, Rouge et Favoris : geste, indicateur, barre de chargement, rendu groupé et tous les réglages d'affichage.
- Feuille de configuration rapide sur Super : « Non-lus uniquement » est désactivé (sans effet sur cet onglet) et l'en-tête précise que les réglages sont globaux.
- Un premier test d'interface du corps de liste a été ajouté pour que ce genre de trou ne repasse plus les gates.

 

Précision sur « Masquer les catégories sans non-lu » : sur Super, comme sur toute vue qui affiche les sujets lus, seules les sections vides disparaissent ; un super favori entièrement lu reste visible.

 

Test : T31 reste valable (marquer deux sujets de catégories différentes, tirer pour rafraîchir, activer le groupement), à refaire sur cette build.

 

Changelog complet : https://github.com/ForumHFR/redface [...] ANGELOG.md
