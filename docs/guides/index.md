# Guides
{: .fs-8 }

Les pages d'accompagnement du projet.
{: .fs-5 .fw-300 }

Cette section regroupe :
- comment installer l'app (Play, F-Droid bêta et dev, GitHub Releases)
- comment contribuer (environnement Docker, tests, rendu visuel, Git) et comment publier une release
- les limitations connues et compromis assumés
- le contexte et les raisons du rewrite, l'historique du nom, l'icône
- l'inventaire des références écosystème HFR (clients tiers, docs MesDiscussions, outillage compagnon)
- le réglage proxy utilisateur, le profiling, la capture de fixtures live

Pour les sources canoniques qui décrivent le projet lui-même, voir la section [Spécifications]({{ site.baseurl }}/specs).
